Spacing utilities new · phase 2

Single-purpose margin & padding helpers generated from the spacing scale, authored with logical properties — so ms/me (inline-start/end) flip when you switch Dir → RTL in the deck, with no extra CSS.

@layer sk.utilities

padding · .sk-p-{n}

.sk-p-2 .sk-p-4 .sk-p-6 .sk-p-8

margin-block · .sk-mb-{n}

.sk-mb-2 .sk-mb-4 .sk-mb-6 last (no margin)

logical inline · .sk-ps-6 · .sk-me-auto

.sk-ps-6 — inline-start pad
.sk-me-auto pushed to inline-end →

Every class maps to a --sk-space-* token and lives in the sk.utilities layer, so your own unlayered CSS overrides it with zero specificity fights and zero !important.
